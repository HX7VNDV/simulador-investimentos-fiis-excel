# Simulador de Investimentos em Fundos Imobiliários

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de Excel, com o objetivo de aplicar conceitos de organização de dados, cálculos financeiros e automação na criação de uma ferramenta para simulação de investimentos em Fundos Imobiliários, FIIs.

A ferramenta permite inserir diferentes parâmetros de investimento e visualizar automaticamente projeções de patrimônio, rendimentos e dividendos ao longo do tempo.

## Funcionalidades

O simulador permite:

* Informar salário mensal
* Definir o percentual da renda destinado a investimentos
* Informar o aporte mensal
* Definir um patrimônio inicial
* Escolher o período de investimento
* Configurar a rentabilidade mensal esperada
* Estimar dividendos mensais e anuais
* Simular diferentes horizontes de investimento
* Selecionar o perfil do investidor
* Visualizar uma sugestão de distribuição entre diferentes tipos de FIIs
* Acompanhar graficamente a evolução do patrimônio

## Estrutura da planilha

O projeto foi organizado em três áreas principais:

### Simulador

Interface principal da ferramenta, onde o usuário informa seus dados e visualiza os principais resultados da simulação.

### Projeção

Apresenta a evolução do patrimônio ao longo do tempo, considerando os aportes mensais e os rendimentos acumulados.

### Base FII

Contém os parâmetros utilizados para definir a distribuição da carteira conforme o perfil de investidor selecionado.

## Conceitos de Excel utilizados

Durante o desenvolvimento foram aplicados recursos como:

* Fórmulas financeiras
* Juros compostos
* Intervalos nomeados
* Validação de dados
* Funções de busca
* Referências entre planilhas
* Formatação de valores monetários e percentuais
* Gráficos dinâmicos
* Automação de cálculos

## Como utilizar

1. Faça o download do arquivo `Simulador_Investimentos_FIIs.xlsx`.
2. Abra o arquivo no Microsoft Excel.
3. Acesse a aba principal do simulador.
4. Preencha os campos destinados ao usuário.
5. Escolha o perfil de investidor.
6. Defina o prazo e as taxas utilizadas na simulação.
7. Analise os resultados calculados automaticamente.
8. Consulte as projeções e gráficos para visualizar a evolução do investimento.

## Objetivo

O objetivo deste projeto é demonstrar a aplicação prática dos conhecimentos adquiridos em Excel por meio da construção de uma ferramenta de simulação financeira.

Os resultados apresentados possuem finalidade exclusivamente educacional e não constituem recomendação de investimento.
